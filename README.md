## このアプリについて

### 🎯 何ができるの？

このWebアプリケーションは、**図面のPNG画像を自動処理**するツールです。具体的には以下のことを行います：

1. **図番の自動読み取り（OCR）**
   - 図面の右上に印刷されている図番（例：`LW25000-00-000`）を自動で読み取ります
   - OCR（光学文字認識）という技術を使って、画像から文字を抽出します

2. **図番の確認と手動修正（新機能！）**
   - OCRで読み取った図番を1枚ずつ確認できます
   - 読み取りミスがあった場合、その場で手動修正できます
   - 図番が読み取れなかった場合も、手動入力で対応可能です

3. **QRコードのプレビューと位置調整（新機能！）**
   - QRコードを配置する前に、実際の見た目をプレビューできます
   - QRコードの位置を**ドラッグ＆ドロップ**で自由に調整できます
   - スライダーで細かい位置調整も可能です
   - QRコードのサイズも調整できます

4. **ファイル名の自動リネーム**
   - 読み取った（または修正した）図番を使って、ファイル名を自動的に変更します
   - 例：`IMG_0001.png` → `LW25000-00-000.png`

5. **一括処理とZIP出力**
   - 100〜200枚の図面を処理できます
   - 各ファイルを1枚ずつ確認してから処理します
   - 処理結果はZIPファイルにまとめてダウンロードできます

### 💡 どんな時に便利？

- 大量の図面をスキャンした後、手作業でファイル名を変更する作業を自動化したい
- 図面にQRコードを追加して、現場でスマホで簡単に図番を確認できるようにしたい
- 図面管理システムに取り込む前の前処理として活用したい

## ライブラリについて

### 📚 使用しているライブラリ

このアプリは、以下の外部ライブラリ（他の人が作った便利なツール）を使っています：

1. **Tesseract.js**（テッセラクト・ジェーエス）
   - **役割**: OCR（画像から文字を読み取る）
   - **公式サイト**: https://tesseract.projectnaptha.com/
   - **説明**: 画像に書かれている文字を自動で認識して、テキストとして取り出すことができます

2. **JSZip**（ジェーエス・ジップ）
   - **役割**: ZIPファイルの作成
   - **公式サイト**: https://stuk.github.io/jszip/
   - **説明**: JavaScriptでZIPファイルを作成できます。処理した画像をまとめてダウンロードするために使います

3. **QRCode.js**（キューアールコード・ジェーエス）
   - **役割**: QRコードの生成
   - **公式サイト**: https://github.com/davidshimjs/qrcodejs
   - **説明**: テキストからQRコード画像を生成できます

### 🌐 CDNとは？

**CDN（コンテンツ・デリバリー・ネットワーク）** とは、インターネット上でライブラリを配信してくれるサービスのことです。

**メリット:**
- 自分のパソコンにライブラリをダウンロードする必要がない
- 常に最新版を使える
- インターネットに接続していれば、どこでも使える

**使い方:**
`index.html` の中に以下のような `<script>` タグを書くだけです：

```html
<script src="https://cdn.jsdelivr.net/npm/tesseract.js@5/dist/tesseract.min.js"></script>
```

これで、ページを開いたときに自動的にライブラリが読み込まれます。

> ⚠️ **注意**: CDNを使うため、**インターネット接続が必要**です。オフラインでは動作しません。

## アプリの起動方法

### 🚀 方法1: ブラウザで直接開く（一番簡単！）

1. **フォルダを開く**
   - 先ほど作成した「図面QRアプリ」フォルダを開きます

2. **index.html をダブルクリック**
   - `index.html` ファイルをダブルクリックします

3. **アプリが起動！**
   - ブラウザにアプリの画面が表示されます
   - これで使えるようになります

> 💡 **ヒント**: もしブラウザで開かない場合は、`index.html` を右クリック → 「プログラムから開く」→「Google Chrome」などを選択してください。

### 🚀 方法2: ローカルサーバーで開く（推奨）

ファイルシステムの制約により、一部のブラウザでは直接開くと動作しない場合があります。その場合はローカルサーバーを使うと確実です。

#### 方法2-1: Visual Studio Code の Live Server を使う

1. **Visual Studio Code をインストール**
   - https://code.visualstudio.com/ からダウンロード

2. **Live Server 拡張機能をインストール**
   - VS Code を開く
   - 左側のメニューから「拡張機能」（四角が4つのアイコン）をクリック
   - 検索バーに「Live Server」と入力
   - 「Live Server」（作者: Ritwick Dey）をインストール

3. **フォルダを開く**
   - VS Code で「ファイル」→「フォルダーを開く」
   - 「図面QRアプリ」フォルダを選択

4. **Live Server を起動**
   - `index.html` を右クリック
   - 「Open with Live Server」をクリック
   - 自動的にブラウザが開き、アプリが表示されます

#### 方法2-2: Python の簡易サーバーを使う

Pythonがインストールされている場合（Macには標準で入っています）：

1. **ターミナル / コマンドプロンプトを開く**
   - Windows: 検索バーで「cmd」と入力
   - Mac: Spotlight で「ターミナル」と検索

2. **フォルダに移動**
   ```bash
   cd パス/図面QRアプリ
   ```
   （例: `cd C:\Users\YourName\Desktop\図面QRアプリ`）

3. **サーバーを起動**
   - Python 3 の場合:
     ```bash
     python -m http.server 8000
     ```
   - Python 2 の場合:
     ```bash
     python -m SimpleHTTPServer 8000
     ```

4. **ブラウザで開く**
   - ブラウザを開いて、アドレスバーに `http://localhost:8000` と入力

#### 方法2-3: npx serve を使う

Node.js がインストールされている場合：

1. **ターミナル / コマンドプロンプトを開く**

2. **フォルダに移動**
   ```bash
   cd パス/図面QRアプリ
   ```

3. **serve を実行**
   ```bash
   npx serve
   ```

4. **表示されたURLをブラウザで開く**
   - 通常は `http://localhost:3000` や `http://localhost:5000`

### 📋 ステップ1: アプリを開く

上記の方法でアプリをブラウザで開きます。

### 📂 ステップ2: 図面ファイルを選択する

画面に2つのボタンがあります：

1. **「📁 フォルダを選択」ボタン**
   - フォルダごと選択したい場合はこちらをクリック
   - フォルダ選択ダイアログが開きます
   - 図面が入っているフォルダを選択します

2. **「🖼️ 複数ファイルを選択」ボタン**
   - 個別にファイルを選びたい場合はこちらをクリック
   - 複数のPNGファイルを選択できます（Ctrlキーを押しながらクリック）

選択すると、画面に「選択されたファイル: ○個」と表示されます。

### 🚀 ステップ3: 処理を開始する

「🚀 処理を開始」ボタンをクリックします。

**処理の流れ:**

1. **OCRエンジンの初期化**（数秒かかります）
   - Tesseract.js が起動します

2. **1枚目のファイルが読み込まれます**
   - 自動的にOCRで図番を読み取ります
   - プレビューモーダルが表示されます

3. **プレビュー画面で確認・調整**

   プレビューモーダルには以下の要素があります：

   **左側：プレビュー画像**
   - 実際の図面画像が表示されます
   - QRコードが配置された状態を確認できます
   - 赤い枠（QRコードの位置）が表示されます

   **右側：設定パネル**

   a) **図番の確認・修正**
   - OCRで読み取った図番が自動入力されています
   - 誤認識があれば、テキストボックスで修正できます
   - 読み取れなかった場合は、手動で入力してください

   b) **QRコード位置の調整**
   - **方法1：ドラッグ＆ドロップ**
     - プレビュー画像上の赤い枠をマウスでドラッグ
     - 直感的に位置を調整できます

   - **方法2：スライダー**
     - X座標スライダー：左右の位置を調整
     - Y座標スライダー：上下の位置を調整
     - QRサイズスライダー：QRコードのサイズを調整

   - **「🔄 位置をリセット」ボタン**
     - デフォルト位置に戻します

   c) **「🔄 プレビューを更新」ボタン**
   - 図番を変更した後、このボタンでQRコードを再生成
   - プレビュー画像が更新されます

4. **確認後のアクション**

   - **「✅ この内容でOK」ボタン**
     - 図番とQRコード位置を確定します
     - 画像が処理されて保存されます
     - 自動的に次のファイルのプレビューが表示されます

   - **「⏭️ スキップ」ボタン**
     - このファイルを処理せずにスキップします
     - スキップしたファイルはエラー一覧に記録されます
     - 次のファイルに進みます

5. **すべてのファイルを確認**
   - 上記の手順を全ファイル分繰り返します
   - 進捗バーで「○/○枚確認中」と表示されます

6. **完了**
   - すべてのファイルの確認が終わると、結果が表示されます

### 💾 ステップ4: 結果をダウンロードする

処理が完了すると、以下の情報が表示されます：

- ✅ 成功: ○件
- ❌ エラー: ○件

**ダウンロード:**

1. **「💾 結果をダウンロード (ZIP)」ボタンをクリック**
2. ZIPファイルがダウンロードされます
   - ファイル名: `drawing_qr_result_20231210_143022.zip`（タイムスタンプ付き）

3. **ZIPファイルを展開**
   - ZIPファイルを右クリック → 「すべて展開」または「解凍」
   - 中には、リネームされ、QRコードが合成された図面が入っています

### 📊 処理ログの確認

画面の下部に「処理ログ」が表示されます：

- 🔵 青色: 情報メッセージ
- 🟢 緑色: 成功メッセージ
- 🔴 赤色: エラーメッセージ

各ファイルの処理結果がリアルタイムで表示されます。

### ⚠️ エラーが発生した場合

図番が読み取れなかったファイルは、「エラーファイル一覧」セクションに表示されます。

**エラーの原因:**
- 図番の位置が想定と異なる
- 図番が汚れている、かすれている
- 図番の書式が異なる（例: `AB12345-00-000`）

**対処法:**
- 座標設定を調整する（後述）
- 手動でファイル名を変更する
- 画像の品質を向上させる（再スキャンなど）

## 座標の調整方法

### 🎯 なぜ座標調整が必要？

図面のスキャン方法や画像サイズによって、図番や□枠の位置がずれることがあります。その場合、`main.js` の設定を調整することで対応できます。

### 🛠️ 設定オブジェクトの場所

`main.js` の冒頭にある `config` オブジェクトを編集します：

```javascript
const config = {
    // OCR対象領域（図番が印刷されている右上の領域）
    ocrRegion: {
        x: 1650,        // 左上のX座標
        y: 50,          // 左上のY座標
        width: 350,     // 幅
        height: 80      // 高さ
    },

    // QRコードを配置する□枠の領域
    qrFrame: {
        x: 1700,        // 左上のX座標
        y: 150,         // 左上のY座標
        width: 240,     // 枠の幅（ピクセル）
        height: 240     // 枠の高さ（ピクセル）
    },

    // その他の設定...
};
```

### 📏 座標の見つけ方

1. **画像をペイントソフトで開く**
   - Windows: ペイント
   - Mac: プレビュー
   - その他: GIMP、Photoshop など

2. **マウスカーソルを図番の左上に合わせる**
   - 座標が表示されます（X, Y）
   - これを `ocrRegion.x` と `ocrRegion.y` に設定

3. **図番の幅と高さを測る**
   - 矩形選択ツールで図番領域を囲む
   - サイズが表示されます（幅, 高さ）
   - これを `ocrRegion.width` と `ocrRegion.height` に設定

4. **□枠も同様に測定**
   - `qrFrame` の値を調整します

### 💡 調整のコツ

- **OCR領域は少し広めに取る**: 図番全体がしっかり入るようにします
- **QRフレームは正確に**: QRコードがはみ出さないように、枠のサイズを正確に測ります
- **テスト処理**: 1〜2枚で試してから、全体を処理すると効率的です

## トラブルシューティング

### ❓ アプリが開かない

**原因1: HTMLファイルが正しく保存されていない**
- 拡張子が `.html` になっているか確認
- ファイル名が `index.html.txt` になっていないか確認

**原因2: ブラウザの問題**
- 別のブラウザで試す（Chrome、Firefox、Edgeなど）
- ブラウザを最新版に更新する

### ❓ 「処理を開始」ボタンが押せない

**原因: ファイルが選択されていない**
- PNGファイルを選択してください
- 選択したフォルダにPNGファイルが入っているか確認

### ❓ OCRで図番が読み取れない

**原因1: 座標がずれている**
- `config.ocrRegion` の座標を調整してください

**原因2: 画像の品質が低い**
- スキャン解像度を上げる（推奨: 300 dpi 以上）
- 画像をクリーンアップする

**原因3: 図番の書式が異なる**
- `config.drawingNumberPattern` の正規表現を変更してください
- 例: `/(AB|CD)\d{5}-\d{2}-\d{3}/` など

### ❓ QRコードが正しく配置されない

**原因: QRフレームの座標がずれている**
- `config.qrFrame` の座標とサイズを調整してください
- 実際の画像で□枠の位置を測定し直してください

### ❓ ZIPファイルがダウンロードできない

**原因1: ブラウザのポップアップブロック**
- ブラウザの設定でポップアップを許可してください

**原因2: ディスク容量不足**
- 十分な空き容量があるか確認してください

**原因3: ブラウザのダウンロード設定**
- ブラウザのダウンロード履歴を確認してください

### ❓ 処理が遅い

**原因: OCR処理は時間がかかります**
- OCR処理自体は1枚あたり5〜10秒程度です
- ただし、各ファイルの確認・調整は手動で行うため、全体の処理時間はユーザー次第です
- じっくり確認しながら進めることで、正確な結果が得られます

### ❓ QRコードが枠からはみ出してしまう

**原因: QRコードのサイズが大きすぎる**
- QRサイズスライダーで小さく調整してください
- または、`main.js` の `config.qrSizeRatio` を変更してください

### ❓ プレビュー画像が表示されない

**原因1: 画像サイズが大きすぎる**
- ブラウザのメモリ制限に達している可能性があります
- 画像サイズを小さくしてから試してください

**原因2: ブラウザの問題**
- ページを再読み込みしてください
- 別のブラウザで試してください

### ❓ ドラッグ＆ドロップが動作しない

**原因: ブラウザの互換性問題**
- スライダーを使って位置を調整してください
- X座標・Y座標スライダーで同じ調整が可能です

### ❓ 図番を変更したのにQRコードが更新されない

**解決方法: 「🔄 プレビューを更新」ボタンをクリック**
- 図番を入力・変更した後は、必ずこのボタンを押してください
- QRコードが新しい図番で再生成されます

### システム要件

- インターネット接続（CDNからライブラリを読み込むため）
- モダンブラウザ（2020年以降のバージョン）
- メモリ: 4GB以上推奨（大量の画像を処理する場合）

### セキュリティについて

- **すべての処理はブラウザ内で完結します**
- 画像がサーバーにアップロードされることはありません
- 完全にオフライン処理（ライブラリ読み込み後）なので安全です

### カスタマイズ

`main.js` の `config` オブジェクトを変更することで、以下をカスタマイズできます：

- OCR対象領域の位置とサイズ
- QRコード配置位置とサイズ
- 図番の正規表現パターン
- QRコードのエラー訂正レベル

---

## 🎉 まとめ

このアプリを使えば、大量の図面ファイルを自動で処理できます。

**メリット:**
- ✅ 手作業でのファイル名変更が不要
- ✅ QRコードで図番を素早く確認できる
- ✅ ブラウザだけで完結、特別なソフト不要
- ✅ 100枚以上の図面も一度に処理可能

何か問題があれば、設定を調整したり、ログを確認したりして対処してください。
